\chapter{Dataset Preparation and Comparative Model Training}
\label{cap:segmentation}
\label{cap:dataset_training}

This chapter describes the datasets and two experiments on the segmentation network. The first compares FCN, DeepLabV3, and LR-ASPP, fine-tuned from pretrained weights on a manually annotated lettuce dataset, and selects LR-ASPP for the robot. Manual annotation was done only for lettuce, because it is time-consuming. The second experiment tests whether LR-ASPP networks trained on SAM~3 masks of the lettuce images, without manual correction, can replace manual annotation. The automatic binary labeling was then extended to all crops, and a network trained on this collection is the one deployed on the robot (Section~\ref{subsec:c4_deployed_network}).

\section{Image acquisition and class definition}
\label{sec:c4_acquisition_classes}

\subsection{Image sources}
\label{subsec:c4_image_acquisition}

All images were recorded in a commercial greenhouse with the same camera as the robot, an Intel RealSense D435 (Section~\ref{subsec:camera}). The color stream was recorded in ROS bags, and the images are frames extracted from these recordings, at $640 \times 480$ pixels. The collection contains 762 lettuce, 878 tomato, and 319 cucumber images, 1959 in total. Figure~\ref{fig:crop_dataset_samples} shows images of the three crops.

  \label{fig:crop_dataset_samples}

\subsection{Semantic classes and labeling targets}
\label{subsec:c4_semantic_classes}

The segmentation labels in this thesis use up to four semantic classes: background, plants, path (the traversable corridor between two crop rows), and covering material (plastic mulch film). The manual lettuce annotations use all four classes (Section~\ref{subsec:c4_lettuce}).

The labels generated with SAM~3 (Section~\ref{subsec:c4_sam_annotation}) follow three configurations, each used to train a separate network:
\begin{itemize}
\item \textbf{Four-class configuration:} background, plants, path, and covering material, matching the four classes of the manual lettuce annotations.
\item \textbf{Three-class configuration:} background, plants, and path.
\item \textbf{Binary configuration:} background and path. This configuration is used both for the lettuce-only binary network and for the final multi-crop dataset.
\end{itemize}
For row following, the path mask is the input of the path extractors, which estimate the centerline (Chapter~\ref{cap:geometric_reference}).

\section{Dataset preparation}
\label{sec:c4_datasets}

The manually annotated lettuce dataset contains 762 image--mask pairs. These masks are the ground truth for all the evaluations of this chapter. They contain four classes (background, plants, path, and covering material), and the path class marks only the corridor the robot should follow, not other visible paths. The same images were also labeled automatically with four, three, and two classes, as described in Section~\ref{subsec:c4_sam_annotation}.

\subsection{Automatic labeling with SAM~3}
\label{subsec:c4_sam_annotation}

Manual annotation takes a lot of human work, so SAM~3 was tested as a replacement. It was run offline with text prompts, and its masks were used for training without inspection or correction, also where manual masks were available, to measure how well a network performs when the annotation is fully automatic. SAM~3 was first used on the lettuce images, where the networks trained on its labels can be evaluated against the manual masks (Section~\ref{sec:c4_supervision_comparison}), and then on all the images of the three crops, to train the network of the robot. The SAM~3 masks are not compared directly with the manual ones.

For each text prompt, SAM~3 returns zero or more masks with a confidence above 0.25, and the pixels with a mask value above 0.5 are assigned to the class of the prompt. The prompts are applied in a fixed order, and a later prompt is written only on pixels still labeled as background, so earlier classes are never overwritten. Pixels not assigned by any prompt remain background. The prompts, in order, are:
\begin{itemize}
    \item \textbf{Four-class lettuce dataset:} \texttt{plants}, \texttt{plastic mulch film}, \texttt{central farm path}
    \item \textbf{Three-class lettuce dataset:} \texttt{plants}, \texttt{central farm path}
    \item \textbf{Binary lettuce dataset:} \texttt{central farm path}
    \item \textbf{Multi-crop dataset:} \texttt{central path}
\end{itemize}
Figure~\ref{fig:sam3_annotation_pipeline} shows the masks of the three prompts on a lettuce image and the resulting four-class label.

\subsection{Tomato and cucumber images}
\label{subsec:c4_tomato_cucumber}

The tomato and cucumber images were labeled only automatically and are used only in the final multi-crop dataset, on which the binary network deployed on the robot is trained. They have no manual ground truth, so they are not part of the quantitative evaluations of Section~\ref{sec:c4_supervision_comparison}.

\subsection{Summary of the datasets}
\label{subsec:c4_dataset_summary}

The datasets of this chapter are:
\begin{itemize}
\item \textbf{Manual lettuce dataset:} 762 lettuce images with manual labels in four classes. It is the ground truth of all the evaluations and the training set of the architecture comparison (Section~\ref{sec:c4_architecture_comparison}) and of the manual baseline (Section~\ref{sec:c4_supervision_comparison}).
\item \textbf{Automatic lettuce datasets:} the same 762 images with automatic labels in four, three, and two classes. They are the training sets of the three networks trained on automatic labels (Section~\ref{sec:c4_supervision_comparison}).
\item \textbf{Multi-crop dataset:} 1959 images, 762 of lettuce, 878 of tomato, and 319 of cucumber, with binary automatic labels. It is the training set of the network deployed on the robot (Section~\ref{subsec:c4_deployed_network}).
\end{itemize}

\subsection{Dataset partitioning}
\label{subsec:c4_dataset_splits}

The lettuce networks use a random 80/10/10 split of the 762 pairs: 609 training, 76 validation, and 77 test images. The validation split selects the best checkpoint, and the test split gives the final scores. The manual baseline and the three networks trained on automatic labels use the same split, so they are tested on the same 77 images. The multi-crop network evaluated in Section~\ref{subsec:c4_deployed_network} is also tested on these 77 images, which were left out of its training data. Its remaining 1882 pairs were split 80/10/10.

The split is random over single images, so the test images are different frames of the same paths as the training images, and the IoU values may overestimate the performance.

The realistic scenario of Section~\ref{sec:c4_supervision_comparison} uses only the 42 test images recorded between parallel rows, from viewpoints the robot can reach. The other test images show more than one path or were taken outside the rows. In these images the manual masks label only the path the robot should follow, when it is visible.

\section{Architecture comparison: FCN, DeepLabV3, and LR-ASPP}
\label{sec:c4_architecture_comparison}

This section compares FCN, DeepLabV3, and LR-ASPP, trained on the manually annotated lettuce dataset with four classes, to choose the network used in the rest of this work: in the comparison between manual and automatic labels (Section~\ref{sec:c4_supervision_comparison}) and on the robot.

\subsection{Model selection and pretrained weights}
\label{subsec:c4_model_selection}

FCN, DeepLabV3, and LR-ASPP were chosen among the implementations available in TorchVision, for practical reasons. All three start from the default TorchVision segmentation weights, trained on a subset of COCO restricted to the 20 categories of Pascal VOC~\cite{torchvision_fcn,torchvision_deeplabv3,torchvision_lraspp}. FCN and DeepLabV3 use a ResNet-50 backbone, and LR-ASPP a MobileNetV3-Large backbone. Only the final $1\times1$ convolutions are replaced by new ones with 4 output channels, one per class: in FCN and DeepLabV3 those of the main and auxiliary classifiers, in LR-ASPP the two of the head, one on the low-level features and one on the processed high-level features~\cite{torchvision_lraspp}.

\subsection{Training configuration and loss formulation}
\label{subsec:c4_training_config}

\subsubsection{Loss function and class weighting}
The loss is the cross entropy, computed for each pixel, which penalizes the model when it estimates a low probability for the target class~\cite[Chapter~4]{geron2026handson}. To keep the classes with many pixels from dominating the training, the models use a weighted cross-entropy loss $\mathcal{L}_{\text{WCE}}$, in which each pixel is multiplied by the weight $w_c$ of its ground-truth class $c$. The weights are computed on the training split only. With $N_c$ the number of pixels of class $c$ in all the training masks and $C$ the number of classes (four in this comparison), the weight of class $c$ is
\begin{equation}
    w_c = \frac{1/N_c}{\frac{1}{C}\sum_{j=0}^{C-1} 1/N_j}.
    \label{eq:class_weights_norm}
\end{equation}
A rare class receives a large weight and a frequent class a small one, and the weights have mean 1.

For FCN and DeepLabV3, which incorporate an auxiliary classifier, the total training objective combines the primary and auxiliary losses with an auxiliary weighting factor of $0.4$:
\begin{equation}
    \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{WCE}}(\text{main}) + 0.4 \cdot \mathcal{L}_{\text{WCE}}(\text{aux}).
    \label{eq:total_training_loss}
\end{equation}
For LR-ASPP, training relies solely on the primary loss $\mathcal{L}_{\text{WCE}}(\text{main})$.

\subsubsection{Data augmentation and two-stage optimization}
Data augmentation is applied only to the training split: horizontal flips with probability 0.5, rotations between $-30^\circ$ and $30^\circ$, and, with probability 0.8, a color jitter of brightness and contrast (factors in $[0.8, 1.2]$) and saturation (factors in $[0.85, 1.15]$). Images are not resized and are normalized with the ImageNet mean and standard deviation. The networks were trained on an NVIDIA GeForce RTX 2080 SUPER with 8~GB of memory, with a batch size of 2, for 200 epochs in two stages:
\begin{enumerate}
    \item \textbf{Epochs 1--10:} the backbone is frozen and only the heads are trained, with AdamW (learning rate $10^{-3}$, weight decay $10^{-4}$) and cosine annealing ($T_{\text{max}} = 200$, $\eta_{\text{min}} = 10^{-6}$). The new output layers make large errors at first, and freezing the pretrained layers keeps the resulting large gradients from damaging their weights.
    \item \textbf{Epochs 11--200:} the backbone is unfrozen, and a new AdamW optimizer uses a learning rate of $10^{-5}$ for the backbone and $10^{-4}$ for the heads, which limits the changes to the pretrained weights. The cosine annealing restarts over the remaining 190 epochs ($T_{\text{max}} = 190$, $\eta_{\text{min}} = 10^{-6}$).
\end{enumerate}

Early stopping was not used, so that the complete loss curves could be recorded. After each epoch the model is evaluated on the validation set, and the weights are saved whenever the validation loss reaches a new minimum.

\subsection{Evaluation metrics and results}
\label{subsec:c4_architecture_results}

The three networks are evaluated on the 77 test images with the intersection over union of each class $c$,
\begin{equation}
    \text{IoU}_c = \frac{\text{TP}_c}{\text{TP}_c + \text{FP}_c + \text{FN}_c},
    \label{eq:eval_iou}
\end{equation}
where $\text{TP}_c$, $\text{FP}_c$, and $\text{FN}_c$ are the true positive, false positive, and false negative pixels of class $c$. The mIoU is the mean over the four classes, background included. Each network is evaluated with the weights of the epoch with the lowest validation loss. The inference time is measured on the training GPU, not on the robot (Section~\ref{subsec:timing}), one image at a time at its original resolution.

FCN and DeepLabV3 reach the same mIoU (0.9253), 1.08 percentage points above LR-ASPP, and LR-ASPP has the lowest IoU in every class (Tables~\ref{tab:c4_architecture_results} and~\ref{tab:c4_architecture_class_iou}). However, LR-ASPP is 7.2 times faster than FCN and 10.6 times faster than DeepLabV3.

The validation loss of FCN and DeepLabV3 reaches its minimum early and then rises while the training loss keeps decreasing, so both networks overfit (Figure~\ref{fig:training_loss_curves}). That of LR-ASPP reaches a plateau around epoch 75 and does not rise. The losses of FCN and DeepLabV3 include the auxiliary term of Eq.~\eqref{eq:total_training_loss}, so their values are not comparable with those of LR-ASPP.

LR-ASPP was selected because it is much faster with a similar mIoU, and speed matters most for a network that must run on the robot in real time.

\section{Manual versus automatic labels}
\label{sec:c4_supervision_comparison}

The same network, LR-ASPP, is trained on five datasets: the manual lettuce labels (the manual baseline), the automatic lettuce labels with four, three, and two classes, and the binary automatic labels of the multi-crop dataset. All five are evaluated against the manual masks of the same 77 lettuce test images.

In the four-class network the IoU of the covering material and of the background is low. Visual inspection showed that the automatic labels segment the covering material poorly and also assign the greenhouse plastic cover to it, which is background in the manual masks. Automatic labels can therefore be poor for less common classes such as the covering material, and they do not replace manual annotation when these classes are needed.

On the complete test set the path IoU of all automatic-label networks drops to 0.39--0.41, while that of the manual baseline does not. The drop comes from the test images recorded from viewpoints the robot cannot reach. In these images the manual masks mark only the path to follow, when it is visible, while the networks trained on automatic labels also mark adjacent paths and the soil outside the corridor, or in front of the camera when there is no path to follow (Figure~\ref{fig:segmentation_comparison_crops}a). These values therefore measure both segmentation errors and the difference between the two kinds of labels.

In the realistic scenario the path IoU of the three automatic-label networks is 5.7 to 6.2 percentage points below the manual baseline.

The automatic-label networks reach their minimum validation loss between epochs 18 and 38. The validation loss of the manual baseline keeps decreasing until a plateau around epoch 75 (Figure~\ref{fig:training_loss_curves}c), and its minimum within the plateau is at epoch 162.

\subsection{Deployed network}
\label{subsec:c4_deployed_network}

The binary configuration was chosen for the robot because the centerline extraction uses only the path class (Chapter~\ref{cap:geometric_reference}). The LR-ASPP network trained on the final multi-crop dataset, with the binary labels of the prompt \texttt{central path}, is the one deployed on the robot and used in Chapters~\ref{cap:platform} and~\ref{cap:experiments}.

Its training data include the lettuce test images, so a second network with the same configuration was trained without them (Section~\ref{subsec:c4_dataset_splits}). Its results estimate the accuracy of the configuration (Table~\ref{tab:c4_results_binary_general}). On the complete test set its path IoU is 0.6369, against 0.3917 for the lettuce-only binary network. Figure~\ref{fig:segmentation_comparison_crops}b shows the deployed network on tomato and cucumber images.
